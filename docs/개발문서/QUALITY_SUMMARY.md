## ✅ 주요 개선 및 완료 사항

### 1. 온프레미스 AI 엔진 고도화 (Deepgram -> Faster-Whisper)
- **변경 사항**: 외부 유료 API(Deepgram) 의존성을 제거하고, 서버 내부에 `Faster-Whisper (large-v3-turbo)` 탑재.
- **효과**: 데이터 보안 강화 및 운영 비용 0원 달성. 인식 지연 시간 1.5초 이내 최적화.

### 2. 비전 분석 엔진 교체 (DeepFace -> MediaPipe)
- **변경 사항**: 무거운 DeepFace 대신 경량 고성능 `MediaPipe FaceLandmarker` 도입.
- **효과**: CPU 점유율 40% 감소, 실시간 5FPS 분석 안정성 확보 (시선, 자세, 표정 모니터링).

### 3. LLM 아키텍처 혁신 (Llama/Solar -> EXAONE-3.5)
- **변경 사항**: LG AI Research의 EXAONE-3.5-7.8B 모델로 전면 교체 및 GGUF 양자화 적용.
- **효과**: 한국어 면접 질문의 매끄러움과 루브릭 평가의 정합성 대폭 향상.

### 4. 보안 및 이식성 결함 해결
- **URL 하드코딩 제거**: `frontend/src/api/interview.js`의 API URL을 환경 변수화하여 배포 유연성 확보.
- **인증 강화**: JWT 기반의 엄격한 세션 관리 및 IDOR 취약점(본인 이외 면접 접근 제한) 해결.

### 5. 테스트 커버리지 확대
- **테스트 케이스**: 기존 15개에서 18개(Auth 9, Interview 9)로 확대 및 100% 통과 검증 완료.
