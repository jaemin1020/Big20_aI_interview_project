# 📖 User Manual (사용자 메뉴얼)

**Big20 AI 면접 플랫폼** 사용자를 위한 단계별 가이드입니다.

---

## 1. 로그인 및 시작하기
1. 웹 브라우저를 통해 서비스에 접속합니다.
2. 회원가입 후 로그인을 진행합니다.
3. 메인 화면에서 '새 면접 시작' 버튼을 클릭합니다.

## 2. 면접 설정 (Setup)
1. **기업 및 직무 선택**: 면접을 보고자 하는 기업명과 목표 직공(예: 백엔드 개발자)을 선택합니다.
2. **이력서 업로드**: 본인의 최신 이력서(PDF 형식)를 업로드합니다.
   - *팁: 상세한 경력 사항이 적힌 이력서일수록 더욱 정교한 면접 질문이 생성됩니다.*
3. **환경 테스트**: 카메라와 마이크 권한을 허용하고, 본인의 얼굴과 목소리가 정상적으로 수집되는지 확인합니다.

## 3. 면접 진행 (Interview)
1. **질문 청취**: 화면에 질문 텍스트가 표시되며 AI 면접관의 음성이 재생됩니다.
2. **답변하기**: '답변 시작' 버튼을 누르고 답변을 진행합니다.
   - 실시간으로 답변 내용이 텍스트로 변환되어 화면에 표시됩니다.
   - 답변 중에 자신의 시선 처리나 긴장도 점수를 실시간으로 모니터링할 수 있습니다.
3. **답변 완료**: 답변이 끝나면 '답변 종료' 버튼을 클릭하여 다음 질문으로 넘어갑니다.

## 4. 결과 확인 (Report)
1. 모든 질문(총 5~10문항)이 끝나면 면접이 종료됩니다.
2. 잠시 후 **종합 분석 리포트**가 생성됩니다.
   - **종합 점수**: 기술, 소통, 인성 분야별 점수 확인.
   - **AI 피드백**: 답변별 강점 및 보완점, 핵심 키워드 정리.
   - **행동 분석**: 면접 전반의 감정 변화 그래프 및 시선 처리 점수.
3. 리포트는 PDF로 다운로드하여 소장할 수 있습니다.

---

## 💡 유의 사항
- 면접 중에는 브라우저 창을 닫거나 새로고침하지 마세요. (진행 상황이 유실될 수 있습니다.)
- 주변 소음이 적고 조명이 밝은 환경에서 진행하는 것을 권장합니다.
