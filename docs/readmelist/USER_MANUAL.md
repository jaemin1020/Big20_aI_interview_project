# 📖 User Manual (사용자 메뉴얼)

**Big20 AI 면접 플랫폼** 사용자를 위한 단계별 가이드입니다. 본 매뉴얼은 실제 구현된 UI 기반으로 작성되었습니다.

---

## 1. 로그인 및 시작하기
1. 웹 브라우저(`localhost:3000`)를 통해 서비스에 접속합니다.
2. 역할(`Candidate/Recruiter`)에 맞는 계정으로 로그인을 진행합니다.
3. 대시보드에서 '새 면접 시작'을 선택하여 세션을 예약합니다.

## 2. 면접 준비 (Setup)
1. **기업 및 직무 프로필 설정**: 지원하고자 하는 기업의 인재상 키워드와 목표 포지션을 설정합니다.
2. **이력서(Resume) 업로드**: 본인의 PDF 이력서를 업로드하면 AI-Worker가 즉시 벡터 파싱을 시작합니다.
3. **디바이스 환경 점검**: 
   - WebRTC를 위한 카메라/마이크 권한을 허용합니다.
   - 화면에 본인의 영상이 나오고 오디오 게이지가 움직이는지 확인합니다.

## 3. 면접 진행 (Interview)
1. **질문 청취 및 자막**: AI 면접관이 RAG 기반으로 생성한 질문을 음성(TTS)으로 전달하며, 화면 상단에 실시간 질문 자막이 표시됩니다.
2. **답변하기**: '답변 시작' 버튼을 누르고 자유롭게 말씀하세요. 
   - **실시간 자막**: 사용자의 발화 내용이 Faster-Whisper(STT)를 통해 실시간으로 텍스트화되어 답변창에 표시됩니다.
   - **실시간 태도 가이드**: 시선이 너무 불안정하거나 목소리가 작을 경우 대시보드에서 경고 알림이 발생합니다.
3. **답변 종료**: 답변을 마치면 '답변 종료'를 클릭합니다. AI가 답변 내용을 분석하여 다음 꼬리질문을 준비합니다.

## 4. 결과 확인 (Report)
1. 정해진 문항이 모두 끝나면 면접 세션이 자동으로 종료(`completed`)됩니다.
2. AI-Worker(GPU)가 전체 대화록과 비전 데이터를 통합하여 종합 리포트를 생성합니다.
3. **분석 내용**:
   - **종합 점수**: 역량별(기술/경험/소통) 점수 방사형 차트.
   - **상세 피드백**: 답변별 우수한 점과 보완이 필요한 점 기술.
   - **비언어적 지표**: 면접 중 감정 변화 그래프 및 시선 처리 불안정 구간 하이라이트.
4. 리포트는 즉시 확인하거나 나중에 '지난 면접 목록'에서 다시 볼 수 있습니다.

---

## 💡 유의 사항
- **네트워크 안정성**: WebRTC 스트리밍을 위해 안정적인 네트워크 환경에서 진행해 주세요.
- **주변 환경**: 시선 추적의 정확도를 위해 조명이 적절하고 배경이 너무 복잡하지 않은 곳을 권장합니다.
- **시스템 복구**: 브라우저가 예기치 않게 종료된 경우, 다시 접속하면 Redis에 저장된 마지막 세션 상태부터 이어서 진행 가능합니다.
