# 🧠 AI Core System (LLM & RAG)

본 프로젝트의 핵심 두뇌 역할을 하는 **EXAONE-3.5** 기반 질문 생성 및 평가 엔진과 **KURE-v1** 기반 RAG 시스템을 상세히 기술합니다.

---

## 1. LLM 엔진: EXAONE-3.5

프로젝트는 LG AI Research에서 개발한 **EXAONE-3.5-7.8B-Instruct** 모델을 사용합니다. 

### ⚙️ 모델 사양 및 로딩
- **포맷**: GGUF (4-bit Q4_K_M 양자화)
- **런타임**: `llama-cpp-python` (GPU/CUDA 가속)
- **컨텍스트 윈도우**: 32,768 토큰 (긴 이력서 및 대화 내역 처리 가능)
- **역할 분담**:
  - `gpu_queue` 워커에서 싱글톤(Singleton) 패턴으로 로드되어 자원 낭비 최소화.
  - 질문 생성 시 토큰 단위로 프론트엔드에 스트리밍 제공.

---

## 2. 시맨틱 임베딩: KURE-v1

한국어 문맥 이해에 최적화된 **KURE-v1** 임베딩 모델을 사용하여 정밀한 RAG(Retrieval-Augmented Generation)를 구현합니다.

- **차원**: 1024차원
- **용도**: 
  - 이력서 섹션별(경력, 기술, 프로젝트) 임베딩.
  - 기업 인재상 및 직무 설명 임베딩.
  - 답변 평가 시 관련 지식 및 모범 답변 검색.

---

## 3. RAG 기반 질문 생성 프로세스

단순한 질문이 아닌, 지원자의 실제 경험에 기반한 **심층 면접 질문**을 생성하기 위해 다음과 같은 절차를 거칩니다.

1. **이력서 파싱**: `pdfplumber`를 이용해 이력서에서 텍스트를 추출하고 섹션별로 분리.
2. **벡터 검색**: 지원한 기업의 인재상과 이력서 내용 간의 유사도를 **pgvector**를 통해 검색.
3. **컨텍스트 구성**: 검색된 이력서 섹션 + 기업 정보 + 지원 직무를 LLM 프롬프트에 주입.
4. **질문 생성**: EXAONE이 해당 컨텍스트 내에서 모순이 없도록 기술 검증 및 경험 공유 질문 생성.
5. **Scenario Branching**: `check_if_transition()` 로직을 통해 직무 전환자 여부를 판단, 적절한 면접 시나리오(Standard vs Transition)를 적용.

---

## 4. 답변 평가 및 리포트 생성

면접 종료 후, AI-Worker는 다음과 같은 리포트를 생성합니다.

- **평가 루브릭**: 질문 생성 단계에서 미리 생성된 평가 가이드라인(JSON)을 기준으로 채점.
- **다각도 분석**: 
  - **기술적 역량**: 답변의 정확성 및 깊이 평가.
  - **의사소통**: 전문 용어 사용의 적절성 및 논리 구조.
  - **비언어적 요소**: Media-Server에서 수집된 시선, 자세, 미소 점수를 LLM 피드백에 통합.
- **최종 결과**: `evaluation_reports` 테이블에 점수, 강점/보완점, 종합 의견을 마크다운 없이 평문으로 저장.
