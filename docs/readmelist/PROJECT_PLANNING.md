# 📋 Project Planning & Strategy (기획 및 전략)

**Big20 AI Interview Project**의 초기 기획 단계와 서비스 전략을 기술합니다.

---

## 1. 프로젝트 비전
본 프로젝트는 기존의 단순 영상 면접 시스템을 넘어, **LLM(대형 언어 모델)**과 **Vision AI**를 결합하여 면접자의 역량을 다각도로 정밀 분석하는 **지능형 면접 솔루션**을 목표로 합니다.

### 🎯 핵심 목표
- **개인화된 질문**: 이력서와 공고를 분석하여 지원자 맞춤형 심층 면접 질문 생성.
- **객관적 태도 분석**: 시선 처리, 자세, 감정 변화를 데이터화하여 객관적 지표 제공.
- **실시간 피드백**: 면접 종료 즉시 AI가 생성한 상세 평가 리포트 제공.

---

## 2. 서비스 페이즈(Phase)별 로드맵

### Phase 1: 기반 인프라 구축
- MSA 기반 Docker 환경 구축.
- PDF 이력서 파싱 및 KURE-v1 기반 벡터 임베딩 시스템 완성.
- PostgreSQL + pgvector를 활용한 RAG(검색 증강 생성) 기반 마련.

### Phase 2: AI 코어 엔진 통합
- EXAONE-3.5 모델을 이용한 질문 생성 및 평가 로직 구현.
- Faster-Whisper(STT) 및 Supertonic-2(TTS) 음성 파이프라인 연결.
- 비동기 처리(Celery + Redis)를 통한 대기 시간 최소화.

### Phase 3: 실시간 미디어 및 분석 고도화
- aiortc 기반 WebRTC 안정화.
- MediaPipe를 활용한 실시간 시선 및 자세 추정 모듈 통합.
- 종합 결과 대시보드 및 PDF 리포트 출력 기능 구현.

---

## 3. 사용자 시나리오 (UX Strategy)
1. **준비**: 사용자는 본인의 이력서를 PDF로 업로드하고, 지원할 기업과 직무를 선택합니다.
2. **환경 테스트**: 카메라와 마이크 상태를 점검하며 면접 환경을 설정합니다.
3. **면접 진행**: AI 면접관의 음성 질문에 따라 답변을 진행하며, 실시간으로 답변 자막과 분석 수치를 확인합니다.
4. **리포트 확인**: 면접이 끝나면 AI가 분석한 직무 적합성 점수와 강점/보완점 리포트를 확인합니다.

---

## 4. 기대 효과
- **기업 측면**: 면접관의 주관적 편향을 배제하고 동일한 기준으로 지원자를 스크리닝 가능.
- **지원자 측면**: 실제 면접과 유사한 환경에서 스스로를 객관적으로 모니터링하고 연습 가능.
