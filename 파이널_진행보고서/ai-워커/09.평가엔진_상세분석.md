본 보고서는 AI-워커 엔진의 핵심 구성 요소 중 하나인 `evaluator.py` 모듈의 내부 구조와 작동 원리를 상세히 분석합니다. 이 모듈은 지원자의 면접 답변을 실시간으로 분석하고, 면접이 끝난 후 심층적인 최종 평가 리포트를 생성하는 역할을 담당합니다.

## 1. 개요 (Overview)

`evaluator.py`는 **'AI 채용 평가 위원장'**의 두뇌와 같은 역할을 합니다. 단순히 점수를 매기는 것을 넘어, 지원자의 답변에서 기술적 전문성, 논리적 구조, 그리고 기업 인재상과의 부합 여부를 정밀하게 검토합니다.

*   **주요 기술 스택**: Python, Celery (비동기 작업), LangChain (AI 오케스트레이션), EXAONE LLM (언어 모델), SQLModel (DB 연동).
*   **파일 위치**: `c:\big20\Big20_aI_interview_project\ai-worker\tasks\evaluator.py`

## 2. 주요 구성 요소 (Key Components)

### 2.1 데이터 구조 정의 (Pydantic Schemas)
AI가 생성할 결과물의 형식을 고정하기 위해 **Pydantic**을 사용합니다. 이를 통해 결과 데이터가 항상 일정한 형식을 유지하도록 보장합니다.

*   **`AnswerEvalSchema`**: 개별 답변 하나에 대한 평가 구조입니다.
    *   `total_score`: 100점 만점 점수.
    *   `rubric_scores`: 루브릭 항목별 세부 점수.
    *   `feedback`: 지원자에게 줄 구체적인 피드백.
*   **`FinalReportSchema`**: 면접 전체를 아우르는 최종 리포트 구조입니다.
    *   기술 이해도, 직무 경험, 문제 해결 능력, 의사소통, 책임감, 성장 의지 등 6개 영역별 점수 및 상세 피드백을 포함합니다.
    *   `strengths` / `improvements`: 구체적인 근거를 포함한 강점과 보완점 리스트.

### 2.2 루브릭 및 인재상 관리
면접의 공정성을 위해 미리 정의된 **평가 기준(Rubric)**과 기업의 **인재상(Ideal)**을 활용합니다.

```python
# 인재상 참고가 필요한 특정 스테이지 정의
COMPANY_IDEAL_STAGES = {
    "communication", "responsibility", "growth", ...
}
```

## 3. 핵심 프로세스 분석 (Core Workflow)

### 3.1 개별 답변 분석 로직 (`_analyze_answer_logic`)
지원자가 답변을 마칠 때마다 호출되는 함수입니다.

1.  **루브릭 조회**: 해당 면접 질문의 성격(기술, 인성 등)에 맞는 평가 기준을 가져옵니다.
2.  **프롬프트 구성**: AI(EXAONE)에게 '냉철한 심사관'의 페르소나를 부여하고, 질문, 답변, 루브릭 정보를 전달합니다.
3.  **AI 연산**: 언어 모델이 답변을 분석하여 점수와 피드백을 산출합니다.
4.  **DB 저장**: 산출된 점수를 `Transcripts` 테이블에 기록하고, 통계 데이터를 업데이트합니다.

### 3.2 최종 리포트 생성 파이프라인 (`generate_final_report`)
면접이 종료되면 모든 답변을 취합하여 하나의 거대한 리포트를 만듭니다.

```python
@shared_task(name="tasks.evaluator.generate_final_report")
def generate_final_report(interview_id: int):
    # 1. 아직 평가되지 않은 답변들 취합
    # 2. Celery group을 이용해 병렬(Parallel)로 모든 답변 동시 평가
    # 3. 모든 개별 평가가 끝나면 finalize_report_task로 전달 (Chain)
    workflow = chain(group(subtasks), finalize_report_task.s(interview_id))
    return workflow.apply_async()
```

### 3.3 리포트 마무리 및 시니어 제언 (`finalize_report_task`)
가장 복잡하고 중요한 단계입니다. AI가 '시니어 면접 위원장'의 관점에서 전체 면접을 총평합니다.

*   **대화 요약**: 전체 대화 내역이 너무 길 경우 중요한 중후반부 위주로 데이터를 정제합니다.
*   **심층 분석**: 기업 인재상 키워드와 지원자의 답변을 비교하여 조직 적합성을 검증합니다.
*   **STAR 기법**: 지원자가 성과를 설명할 때 논리적인 구조를 갖췄는지 평가합니다.

## 4. 기술적 포인트 (Technical Highlights)

1.  **병렬 처리 (Parallelism)**: 면접 질문이 많을 경우 하나씩 평가하면 시간이 오래 걸립니다. Celery의 `group`을 사용하여 여러 답변을 동시에 평가함으로써 리포트 생성 시간을 획기적으로 단축했습니다.
2.  **페르소나 엔지니어링**: AI에게 단순 텍스트 처리가 아닌 '전문 채용 위원장'의 역할을 부여하여 리포트의 톤앤매너를 전문적으로 유지합니다.
3.  **안전 장치 (Fallback)**: LLM 연산 중 오류가 발생하거나 데이터가 부족할 경우에도 시스템이 멈추지 않고 기본 점수를 산출하여 리포트를 생성하는 방어적 코드가 구현되어 있습니다.
