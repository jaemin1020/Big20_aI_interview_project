# ERR-06: 질문 정제 로직 물음표(?) 의존성 오류

- **오류 코드**: ERR-06  
- **카테고리**: LLM / 프롬프트  
- **심각도**: 🟠 MEDIUM  
- **상태**: ✅ 해결 완료  
- **관련 파일**: `ai-worker/tasks/question_generator.py`

---

## 3.2.1 문제 정의

AI 생성 질문 후처리(정제) 로직이 물음표(`?`)의 존재 여부를 기준으로 동작하였으나, 9/10/11/13/14번 단계의 가이드에서 `"물음표 사용 금지, ~주세요로 끝낼 것"` 제약이 있어 정제 로직이 제대로 작동하지 않는 문제가 발생하였습니다.

- **현상**: `"이 단계에서는..."` 형태의 메타 발화가 물음표가 없어 정제 로직에 걸리지 않고 그대로 출력
- **재현 조건**: narrative 카테고리 단계(9,11,13번) 및 그 꼬리질문 단계에서 발생

---

## 3.2.2 문제 영향 분석

- **출력 품질 영향**: 면접관이 아닌 시나리오 설계자처럼 보이는 텍스트가 지원자에게 노출
- **정제 로직 신뢰성 영향**: 물음표가 없는 정상 문장(~주세요)도 일부 잘못 처리

---

## 3.2.3 문제 파악 과정

**원인**: 정제 로직이 물음표 의존적으로 설계됨

```python
# [문제 코드] 수정 전 정제 로직
if '?' in final_content:
    # 물음표 이후 부연 설명만 제거
    final_content = final_content[:final_content.rfind('?') + 1]
# → 물음표가 없으면 정제 스킵 → 메타 발화가 그대로 통과
```

9번/11번/13번 단계 가이드:
```
# interview_scenario_transition.py L136
"guide": "...모든 질문은 반드시 '~주세요.'로 끝내고 물음표를 사용하지 마십시오."
```

물음표 없이 `"~주세요."` 로 끝나는 메타 발화(`"이 단계에서는 협업을 검증하고자 합니다. 아래 내용을 참고해 주세요."`)가 정제 로직을 통과함.

---

## 3.2.4 해결 접근 전략

- **물음표 의존 정제 → 의미 패턴 기반 정제**로 전환
- 메타 발화에서 자주 등장하는 키워드/패턴을 정규식으로 정의하여 탐지 및 제거

---

## 3.2.5 해결 도출 및 실행

**① 메타 발화 패턴 정규식 (물음표 유무와 무관하게 동작)**

```python
# [수정 후] question_generator.py L510-518
meta_patterns = [
    r'(그렇다면|따라서|이에|제공된|분석하여)\s*(지원자의|내용을|부족한|파악하여).*?(제시하겠습니다|드리겠습니다|하겠습니다|질문입니다)[\.\s]*',
    r'(이\s*질문은|의도는|검증합니다|의도함|확인합니다|요구하여).*',
    r'지원자가\s*.*라고\s*말했다면.*',
    r'위\s*질문은\s*.*',
    r'본\s*질문은\s*.*',
]
for pattern in meta_patterns:
    final_content = re.sub(pattern, '', final_content, flags=re.IGNORECASE | re.DOTALL)
```

**② 서두 레이블 제거 (물음표 없는 형태 포함)**

```python
# [수정 후] question_generator.py L521-533
label_patterns = [
    r'^\**지원자의?\s*답변\s*요약\s*(및\s*꼬리질문)?:\**\s*',
    r'^\**심층\s*질문:\**\s*',
    r'^\**꼬리질문:\**\s*',
    r'^\**질문:\**\s*',
    r'^\d+\.\s*',
    r'^-\s*',
]
```

**③ 물음표 없는 문장도 처리하는 커팅 로직**

```python
# [수정 후] question_generator.py L566-576
if '?' in final_content:
    cut_patterns = ["이 질문은", "질문의 의도", "의도는", "확인하고자 함"]
    for pattern in cut_patterns:
        if pattern in final_content:
            final_content = final_content.split(pattern)[0].strip()
# → 물음표 없는 경우는 meta_patterns에서 이미 처리됨
```

---

## 3.2.6 해결 결과

- **Before**: `"~주세요."` 로 끝나는 메타 발화가 정제 로직을 우회하여 출력
- **After**: 물음표 유무와 무관하게 의미 패턴 기반으로 메타 발화를 탐지 및 제거
- **교훈**: 정제 로직은 특정 문장 부호(물음표, 마침표)에 의존하면 안 되며, 출력 형식이 달라질 수 있는 경우 의미 단위(메타 발화 패턴)로 탐지해야 함
