# ERR-01: AI 면접관 메타 발화 생성 오류

- **오류 코드**: ERR-01  
- **카테고리**: LLM / 프롬프트  
- **심각도**: 🔴 HIGH  
- **상태**: ✅ 해결 완료  
- **관련 파일**: `ai-worker/tasks/question_generator.py`, `ai-worker/config/interview_scenario_transition.py`

---

## 3.2.1 문제 정의

면접 진행 중 9번(협업/소통), 11번(책임감/가치관), 13번(성장가능성) 단계에서 AI 면접관이 직접적인 질문 대신 질문의 의도나 가이드를 설명하는 부적절한 텍스트를 생성하는 현상이 발생하였습니다.

- **현상**: `"이 단계에서는 지원자의 협업 경험을 검증하고자 합니다. 다음 질문을 고려해 보세요..."` 와 같이 질문이 아닌 시나리오 설명 텍스트 출력
- **재현 조건**: 신규 질문 단계(9/11/13번) 진입 시마다 발생
- **발생 비중**: 전체 오류 대비 약 25%로 가장 높은 빈도

---

## 3.2.2 문제 영향 분석

- **UX 영향**: 지원자가 면접관의 의도 설명 문장을 보게 되어 몰입감 저해
- **서비스 신뢰도 영향**: AI 면접관의 전문성이 훼손되어 제품 신뢰도 저하
- **재현율**: 9/11/13번 단계 진입 시 약 70% 이상 확률로 발생

---

## 3.2.3 문제 파악 과정

기술적 원인을 4가지로 규명하였습니다.

**① 프롬프트 역할 충돌**  
`PROMPT_TEMPLATE`에 `"꼬리질문 하나를 생성하라"` 는 지시가 전 단계에 고정되어 있어, 신규 질문 단계(9/11/13번)에서도 AI가 이전 답변 기반 꼬리질문을 생성하려다 가이드 형식으로 이탈하는 현상 발생.

```python
# [수정 전] 고정된 mode_task_instruction
mode_task_instruction = "제공된 정보를 분석하여 가장 예리한 꼬리질문 하나를 생성하십시오."
# → 9/13번(새 주제 시작)에도 동일하게 적용되어 역할 충돌
```

**② 정제 로직의 물음표(?) 의존성**  
9번 단계 가이드에 `"물음표 사용 금지, ~주세요로 끝낼 것"` 제약이 있어 기존 물음표 기반 정제 로직이 작동 불가.

**③ LLM 페르소나 이탈**  
위 두 충돌로 모델이 면접관이 아닌 시나리오 설계자 역할로 오인하여 메타 발화 생성.

**④ 11번 단계 특수성 미반영**  
자기소개서를 RAG로 인용해야 하는 11번 단계가 일반 인재상 질문과 동일하게 처리됨.

---

## 3.2.4 해결 접근 전략

- **고정 프롬프트 → 동적 프롬프트**: 단계별로 다른 미션(`mode_task_instruction`)을 주입하는 변수형 구조로 전환
- **정제 로직 강화**: 물음표 의존 방식 → 메타 발화 패턴 감지 방식으로 교체

---

## 3.2.5 해결 도출 및 실행

**① PROMPT_TEMPLATE 개선**

```python
# [수정 후] question_generator.py L440-463
mode_task_instruction = "..."  # 기본값 유지, 단계마다 덮어씀

elif s_name in ['communication', 'growth']:
    # 9번, 13번: 새 주제로 인성 질문
    mode_task_instruction = (
        "인재상과 이력서를 결합하되, 기술적 성취가 원인이 아닌 "
        "'협업 태도'와 '성장 의지'가 질문의 주인공이 되게 하십시오."
    )
elif s_name == 'responsibility':
    # 11번: 자기소개서 인용 인성 질문
    mode_task_instruction = (
        "자기소개서에서 나타난 지원자의 핵심 가치관을 파악하여 "
        "인재상과 연결하십시오. 오직 인성적인 면모를 80자 이내로 물으십시오."
    )
```

**② 정제 로직 보강 (메타 패턴 감지)**

```python
# [수정 후] question_generator.py L510-518
meta_patterns = [
    r'(이\s*질문은|의도는|~라고\s*답변했다면|검증합니다|의도함|확인합니다).*',
    r'지원자가\s*.*라고\s*말했다면.*',
    r'위\s*질문은\s*.*',
]
for pattern in meta_patterns:
    final_content = re.sub(pattern, '', final_content, flags=re.IGNORECASE | re.DOTALL)
```

**③ 11번 RAG 최적화**

```python
# [수정 후] question_generator.py L319-346
if next_stage.get("stage") == "responsibility":
```

## 3.2.6 해결 결과

- **Before**: 9/11/13번 단계 진입 시마다 `"이 단계에서는..."` 형태의 메타 발화 텍스트 생성
- **After**: `mode_task_instruction` 도입 후 해당 단계에서 정상적인 면접 질문 생성
- **교훈**: LLM 프롬프트는 단계별 역할을 명확히 분리해야 하며, 정제 로직은 형식(물음표)이 아닌 의미 패턴 기반으로 설계해야 함
