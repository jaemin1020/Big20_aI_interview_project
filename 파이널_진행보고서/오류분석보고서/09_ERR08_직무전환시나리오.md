# ERR-08: 직무 전환 시나리오 미동작 (전공 키워드 중복 오류)

- **오류 코드**: ERR-08  
- **카테고리**: 비즈니스 로직  
- **심각도**: 🟠 MEDIUM  
- **상태**: ✅ 해결 완료  
- **관련 파일**: `backend-core/utils/interview_helpers.py`, `ai-worker/utils/interview_helpers.py`, `fca7b773` 대화 분석 보고서

---

## 3.2.1 문제 정의

전공이 `전자공학`이고 지원 직무가 `개발`인 지원자(직무 전환자)의 경우, `interview_scenario_transition.py`(직무 전환 시나리오)가 선택되어야 하나 표준 시나리오(`interview_scenario.py`)가 실행되는 오류가 발생하였습니다.

- **현상**: 전자공학 전공 지원자가 개발직 지원 시 직무 전환 면접이 아닌 일반 면접으로 진행됨
- **재현 조건**: 전기/전자/기계공학 계열 전공자가 IT 직무 지원 시 발생

---

## 3.2.2 문제 영향 분석

- **면접 적절성 영향**: 전환 배경, 학습 동기, 포트폴리오 등 전환자 특화 질문이 누락됨
- **평가 공정성 영향**: 전환자를 IT 전공자와 동일한 기준으로 평가하여 불공정한 결과 발생

---

## 3.2.3 문제 파악 과정

**원인 A - backend-core: `전자` 키워드 IT 전공군 포함**

```python
# [문제 코드] backend-core/utils/interview_helpers.py
tech_major_keywords = ['컴퓨터', '소프트웨어', '정보통신', '전기', '전자', 'IT', ...]
#                                                          ↑        ↑
#                                              이공계 키워드가 IT 전공으로 분류됨

def check_if_transition(major, target_role):
    is_tech_major = any(kw in major for kw in tech_major_keywords)
    # '전자공학' → '전자' 매칭 → is_tech_major=True → 전환자 판별 실패
    if is_tech_role and not is_tech_major:
        return True  # 실제로 여기 도달 못 함
```

**원인 B - ai-worker: `공학` 키워드 개발직 전공으로 포함**

```python
# [문제 코드] ai-worker/utils/interview_helpers.py
role_to_major_keywords = {
    "개발": ["컴퓨터", "소프트웨어", "공학", "전산", ...],
    #                                  ↑ '공학'이 포함되어 전자/기계공학도 IT 전공으로 판별
}
```

**원인 C - 인터뷰 시나리오 파일 경로 하드코딩**

```python

```

## 3.2.4 해결 접근 전략

- **키워드 정밀화**: IT 핵심 전공(컴퓨터, 소프트웨어, 정보통신)과 이공계 전공(전기, 전자, 기계)을 분리
- **로직 통합**: backend-core와 ai-worker가 동일한 판별 로직을 공유하도록 통일
- **경로 동적 처리**: Windows/Docker 환경을 모두 지원하는 경로 탐색 로직 적용

---

## 3.2.5 해결 도출 및 실행

**① 키워드 정밀화**

```python
# [수정 후] interview_helpers.py
# IT 핵심 전공만 포함 (전기/전자 제거)
it_major_keywords = ['컴퓨터공학', '소프트웨어', '정보통신', '컴퓨터과학', 'IT', '인공지능', '데이터']

# 개발 직무 전공 키워드에서 '공학' 제거
role_to_major_keywords = {
    "개발": ["컴퓨터공학", "소프트웨어", "정보통신", "전산"],  # '공학' 제거
}
```

**② 경로 동적 처리**

```python
# [수정 후] ai-worker/config/interview_scenario.py
import os, sys

docker_path = "/backend-core/config/interview_scenario.py"
local_path  = os.path.join(os.path.dirname(__file__), "..", "..", "backend-core", "config", "interview_scenario.py")

target_path = docker_path if os.path.exists(docker_path) else os.path.abspath(local_path)
```

## 3.2.6 해결 결과

- **Before**: 전자공학 전공자가 개발직 지원 시 표준 시나리오로 진행
- **After**: IT 전공 키워드 정밀화 후 전환자 판별 정확도 향상, 직무 전환 시나리오 정상 동작
- **교훈**: 전공/직무 키워드 매칭은 단어 수준의 포함 여부보다 정확한 분류 체계(IT 핵심 전공 vs 이공계 전공)로 구분해야 하며, 경로는 항상 환경 독립적으로 설계해야 함
