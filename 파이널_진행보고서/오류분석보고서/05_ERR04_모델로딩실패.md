# ERR-04: ExaoneLLM 모델 최초 로딩 지연 / 실패 오류

- **오류 코드**: ERR-04  
- **카테고리**: 모델 / GPU  
- **심각도**: 🔴 HIGH  
- **상태**: ✅ 해결 완료  
- **관련 파일**: `ai-worker/utils/exaone_llm.py`, `ai-worker/tasks/question_generator.py`

---

## 3.2.1 문제 정의

GPU 워커 시작 시 또는 첫 면접 질문 생성 요청 시 EXAONE 모델 로딩에 실패하거나, 로딩 성공 이후에도 첫 추론에 30초 이상 소요되는 현상이 발생하였습니다.

- **현상 A**: `Failed to preload model: [Errno 2] No such file or directory` - 모델 파일 경로 오류
- **현상 B**: 모델은 로딩되었으나 첫 질문 생성 응답에 30~60초 소요(콜드 스타트 지연)
- **재현 조건**: Docker 컨테이너 재시작 후 첫 면접 시작 시

---

## 3.2.2 문제 영향 분석

- **서비스 영향**: 첫 면접 질문이 생성되지 않거나 지나치게 긴 대기 발생
- **사용자 영향**: "연결 중..." 상태가 30초 이상 지속되어 이탈 가능성 증가
- **운영 영향**: 컨테이너 재시작마다 초기화 비용 반복 발생

---

## 3.2.3 문제 파악 과정

**원인 A - 경로 불일치**

Docker 환경에서는 `/app/models/` 경로, 로컬 Windows 환경에서는 `C:\big20\...` 경로를 사용해야 하는데, 하나의 경로만 하드코딩되어 있었습니다.

```python
# [문제 코드] question_generator.py
model_path = "/app/models/EXAONE-3.5-7.8B-Instruct-Q4_K_M.gguf"
# → Windows 로컬 실행 시 파일 없음 오류
```

**원인 B - 싱글톤 미적용 / 콜드 스타트**

`get_exaone_llm()` 함수가 호출마다 새로운 모델 인스턴스를 생성하거나, 워커 시작 시 미리 로딩하지 않아 첫 요청의 콜드 스타트 지연이 발생했습니다.

---

## 3.2.4 해결 접근 전략

- **경로 이중화**: Docker 경로 → 로컬 경로 순으로 자동 선택하는 폴백 로직 적용
- **싱글톤 패턴**: 모델 인스턴스를 전역에 한 번만 로드하고 재사용
- **Preload 태스크**: 면접 시작 신호를 받으면 즉시 모델을 GPU 메모리에 올려놓는 사전 로딩 메커니즘 도입

---

## 3.2.5 해결 도출 및 실행

**① 경로 자동 선택 로직**

```python
# [수정 후] question_generator.py L23-25
local_path  = r"C:\big20\Big20_aI_interview_project\ai-worker\models\EXAONE-3.5-7.8B-Instruct-Q4_K_M.gguf"
docker_path = "/app/models/EXAONE-3.5-7.8B-Instruct-Q4_K_M.gguf"
model_path  = docker_path if os.path.exists(docker_path) else local_path
```

**② Preload 태스크 도입**

```python
# [수정 후] question_generator.py L71-84
@shared_task(name="tasks.question_generator.preload_model")
def preload_model_task():
    from utils.exaone_llm import get_exaone_llm
    try:
        logger.info("🔥 [Preload] Starting EXAONE model preloading...")
        get_exaone_llm()  # 싱글톤: 이 시점에 GPU 메모리 로드
        logger.info("✅ [Preload] EXAONE model preloaded inside Celery worker.")
        return {"status": "success"}
    except Exception as e:
        logger.error(f"❌ [Preload] Failed: {e}")
        return {"status": "error", "message": str(e)}
```

**③ 싱글톤 패턴 (exaone_llm.py)**

```python
# utils/exaone_llm.py
_llm_instance = None

def get_exaone_llm():
    global _llm_instance
    if _llm_instance is None:
        _llm_instance = ExaoneLLM(model_path=model_path)
    return _llm_instance
```

---

## 3.2.6 해결 결과

- **Before**: 첫 면접 질문 생성 시 30~60초 지연, 경로 오류로 실패 발생
- **After**: 면접 시작 API 호출과 동시에 `preload_model_task`가 실행되어, 첫 질문 요청 도착 시 모델이 이미 메모리에 로드된 상태
- **교훈**: LLM 모델은 요청 시점이 아닌 워커 시작 시점 또는 세션 시작 시점에 미리 로딩해야 하며, 개발/운영 환경의 파일 경로 차이는 폴백 로직으로 자동 감지해야 함
